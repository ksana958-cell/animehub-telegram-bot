# AnimeHUB | Dream — админ-панель

Эта версия добавляет полноценную админ-панель поверх существующего бота. Она не переносит текущую базу данных в другую папку: `DATA_FILE` и `TITLES_FILE` оставлены совместимыми с текущей конфигурацией, чтобы обновление не создало «пустую» базу после деплоя.

## Как открыть

В личном чате с ботом:

`/admin`

У администратора также появляется кнопка **🛠 Админ-панель** в главном меню. Панель намеренно не работает в групповых чатах.

## Разделы

### 📊 Дашборд

Показывает:
- общее число пользователей и активированных профилей;
- количество Friend/VIP и заблокированных пользователей;
- число тайтлов, Hot и Top-150;
- число постов и статистику публикаций;
- количество предложений и новых заявок;
- статистику рассылок;
- популярные разделы;
- аптайм текущего процесса.

### 🎬 Тайтлы

Можно:
- листать весь каталог;
- искать тайтлы по названию или ID;
- создать новый тайтл;
- редактировать основные поля;
- переключать Hot;
- менять доступ `free → friend → vip`;
- смотреть пользовательский предпросмотр карточки;
- удалять тайтл с подтверждением.

При удалении бот очищает ссылки на этот тайтл из избранного, статусов пользователей, прогресса Top-150 и реестра постов.

Новый тайтл создаётся командой из панели в формате:

`Название | id_taitla`

После создания остальные поля заполняются через кнопки.

### 📝 Посты

Можно:
- создать пост через безопасный предпросмотр;
- опубликовать пост напрямую;
- листать посты, известные боту;
- открыть пост в канале;
- редактировать пост;
- сделать репост;
- привязать пост к тайтлу;
- удалить пост из канала с подтверждением.

Для фото-постов добавлена проверка ограничения Telegram на подпись до 1024 символов. Ссылки кнопок проверяются на формат `https://...`.

### 👥 Пользователи

Можно:
- листать пользователей;
- искать по Telegram ID, username или имени;
- видеть профиль, уровень доступа и пользовательскую статистику;
- назначать `free`, `friend` или `vip`;
- блокировать и разблокировать;
- отправлять личное сообщение;
- root-администратору — повышать и снимать обычных администраторов.

Root-admin нельзя заблокировать через панель.

### 📩 Предложения

`/suggest` теперь сохраняет предложения в базе, а не только пересылает сообщение админу.

Статусы:
- 🆕 Новое
- 🕒 В планах
- ✅ Выполнено
- ❌ Отклонено

При смене статуса бот пытается уведомить автора предложения.

### 📢 Рассылка

Администратор вводит текст, бот сначала показывает предпросмотр и только после отдельного подтверждения рассылает сообщение всем активированным и не заблокированным пользователям.

После завершения показывает число успешных и неуспешных доставок.

### 🔐 Доступы

Панель показывает только факт наличия `ACCESS_CODE_VIP` и `ACCESS_CODE_FRIEND`, но никогда не выводит сами секреты.

Можно создать одноразовую ссылку-приглашение уровня:
- `friend`
- `vip`

Root-admin также может добавить нового администратора по Telegram ID.

### 🧰 Система

Показывает:
- username бота;
- канал;
- статус бота в канале;
- фактическую папку текущей базы;
- размер `bot_data.json` и `titles.json`;
- свободное место на диске;
- состояние BOT_TOKEN без показа значения;
- настройку drop pending updates.

Кнопка **💾 Сделать резервную копию** создаёт timestamp-копии базы и каталога в подпапке `backups` рядом с текущим файлом базы.

### 📜 Журнал

Хранит до 200 последних административных действий, включая:
- изменение тайтлов;
- изменение пользовательского доступа;
- блокировки;
- админские роли;
- публикации и редактирование постов;
- репосты;
- рассылки;
- смену статусов предложений;
- резервные копии.

Root-admin может очистить журнал.

## Важные изменения данных

В `bot_data.json` автоматически добавятся новые безопасные поля:

- `suggestions`
- `audit_log`
- `stats.broadcasts_sent`
- `stats.broadcast_recipients`

Старый файл базы остаётся совместимым: отсутствующие поля будут созданы автоматически.

## Деплой

1. Сделайте резервную копию текущего `bot_data.json` и `titles.json`.
2. В GitHub замените текущий `animehub_bot.py` содержимым `animehub_bot_admin_v1.py` и назовите файл снова `animehub_bot.py`.
3. Убедитесь, что настоящий `BOT_TOKEN` по-прежнему находится только в переменных окружения BotHost.
4. Обновите проект из Git / пересоберите контейнер.
5. После запуска проверьте логи.
6. Напишите боту `/admin` в личном чате.

## Минимальный тест после обновления

1. `/start` — обычное меню работает.
2. `/admin` — открывается панель только у администратора.
3. `🎬 Тайтлы` — список открывается, тестовый тайтл можно просмотреть.
4. `👥 Пользователи` — ваш профиль администратора отображается.
5. `📩 Предложения` — отправьте с другого аккаунта `/suggest тест`, предложение должно появиться в панели.
6. `📝 Посты` — создайте тестовый черновик и отмените его.
7. `🧰 Система` — проверьте статус канала и создайте резервную копию.
8. `📜 Журнал` — предыдущие действия должны появиться в журнале.

## Что намеренно не менялось

В этой сборке не выполняется миграция с JSON на SQLite и не меняется расположение существующей базы. Это отдельные изменения, которые безопаснее делать после проверки админ-панели.
